# Toby Tebbs — Quantitative & Data Science Portfolio

A curated portfolio of MATH 3190 (Fundamentals of Data Science) coursework.

The homepage highlights quantitative methods most relevant to data science and quantitative research, while the Coursework Archive preserves the complete assignment collection.

## Build

This is a Quarto website. From the project directory:

```bash
quarto render
```

The rendered site is written to `docs/` for GitHub Pages.
